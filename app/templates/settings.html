Direct connections (host ports)

Records TCP connections made straight to this host's IP addresses (LAN or Tailscale ip:port), i.e. traffic that never passes through NPM. Reads the kernel connection table, so it needs network_mode: host and cap_add: [DAC_READ_SEARCH]. Only connection counts are available: no path, status or user-agent.

Cloudflare tunnel traffic

Tunnelled services never pass through NPM, so remote traffic is pulled from Cloudflare's GraphQL Analytics API. Create an API token (My Profile → API Tokens) with Account Analytics: Read and Zone: Read (or Zone Analytics: Read) permissions. Free plans keep roughly one day of detailed data, so it is polled continuously.
